Trust the process. Inspect the limits.

Coverage & checks

Analytical rules

  1. Verify SHA-256 fingerprints of three pinned source files.
  2. Retain the latest available compiled snapshot per process across the selected files.
  3. Count each process + award ID once. Keep every excluded award with its exclusion reason.
  4. Restrict headline metrics to active, positive GBP awards dated 2022–2024.
  5. Attribute only sole-supplier awards with a usable identity. Hold back unresolved conflicts, placeholder suppliers and flagged notice discrepancies. Apply only exact, documented registration/name approvals.
  6. Run SQL conservation checks and R sensitivity analysis before updating output files.

What this cannot establish

These snapshots are not a complete historical register of all UK procurement. Award values are not transactions; multi-award processes and frameworks may still represent overlapping economic commitments. Missingness, publication rules and revisions can change apparent trends. No realized savings, supplier performance, misconduct, or causal effects are inferred.

Concentration describes a buyer's observed attributable portfolio—not a legally defined market. Bidder-count comparisons and renewal recommendations are deferred until source coverage can support them.
