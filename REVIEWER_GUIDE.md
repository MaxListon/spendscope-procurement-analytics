# Independent reviewer packet

No outside reviewer response is claimed. This packet is ready for a real analyst, procurement professional or instructor; it has not been sent to anyone.

## Thirty-minute review

1. Follow the README in a clean checkout. Run Python and R tests and artifact verification. Record environment versions and any setup failure.
2. Choose five random registration-audit cases, including one conflict and one unavailable case. Inspect the cited registry and source notice. Assess whether the recorded label is supported and whether an ambiguous case should remain unresolved.
3. Recalculate one buyer HHI from attributable supplier totals. Explain why its eligible and attributable denominators differ.
4. Compare process and buyer/quarter uncertainty results. Identify a recommendation that changes under a broader dependence assumption.
5. Use the dashboard on a narrow screen. Locate evidence, filter buyers, download a CSV and open an original notice without guidance.

## Feedback to record

For each issue: artifact/record, expected behavior, observed behavior, source evidence, severity, proposed correction and whether the result changes a business conclusion. Distinguish a source-data ambiguity from a software defect.

## Acceptance criteria

- Setup can be reproduced without undocumented steps.
- No award value is multiplied by supplier joins.
- Missing/conflicting evidence stays visible; no unsupported identity merge is accepted.
- A reviewer can explain coverage, registry evidence and each resampling unit.
- Recommendations follow from observed results without claiming payments, savings, causal effects or misconduct.
- Any unresolved material finding is documented before the project is described as independently reviewed.
